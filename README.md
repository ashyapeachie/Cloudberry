# Cloudberry

## 🍓Overview
Cloudberry is an AI-powered wellness sanctuary designed to provide a calm, supportive space for reflection and self-care.

Users can their moods, write journal entries, receive personalized reflections from the Cloudberry Reflection Agent, and nurture a virtual cloud companion that grows alongside their wellness journey.

## 🌤️Features 
- mood tracking
- journaling
- reflection agent
- cloud companion

## 📚Tech Stack
- ASP.NET Core MVC
- C#
- SQLite
- Entity Framework Core
- GitHub Copilot
- GitHub
