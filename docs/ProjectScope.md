# Cloudberry

## Project Vision
Cloudberry is an AI-powered wellness santuary designed to help users reflect on their
emotions through mood tracking, journaling, and AI-generated reflections!

The application combines a calming cloud-themed experience with practical wellness
tools in a supportive and engaging environment.

## Target Audience
- college students
- young professionals
- individuals seeking a gentle wellness tool

## Core Featues
Mood Tracking
- users can record their daily moods
Journaling
- users can create free-form journal entries
Cloudberry Reflection Agent
-generates reflections based on mood and journal entires
Dashboard
- displays recent moods, journal entries, reflections, and companion progress

## Technology Stack
- ASP.NET Core MVC
- C#
- SQLite
- Entity Framework Core
- GitHub Copilot
- GitHub
